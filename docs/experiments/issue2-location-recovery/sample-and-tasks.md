# #2 V0 样本与任务冻结:20 件真实物品 + 移位/找回/纠正脚本 + 记录模板

> 配套 [experiment-plan.md](./experiment-plan.md)。本文件一经用户授权启动即**冻结**:清单(§1)、脚本(§3)、打点字段(§4)不再改动;试验中发现的脚本缺陷如实记录在 `protocol_deviation`,不现场改规则。
> 参与人:**用户本人**(招募自己即可,单人户主模式);研究员可由用户自兼,此时「研究员读卡」步骤改为自我出声思考(think-aloud),并在记录中标 `wizard=self`。

## 1. 样本冻结(登记表 A)

### 1.1 选择标准

**高频移动物(≥14 件,主体)**——同时满足:

1. 现实中**每周至少一次**被拿起且放回位置不固定(钥匙、充电宝/充电线、耳机、遥控器、剪刀/指甲刀、常用药品盒、雨伞、口罩、证件夹、数据盘、小工具…);
2. 参与人**说不清它现在在哪**或只凭记忆猜(正好是 #2 的目标失真场景);
3. 物品可安全移动(非易碎/危险/他人专属)。

**稳定锚点(≤6 件,对照侧写)**:换季或数月才动一次、有固定收纳位的物品(备用滤芯、工具箱、保修卡夹、装饰品…)。用途:在**同样被故意移位**的条件下,对比两类物品走同一恢复路径的耗时/线索利用率,为 V2 的 H1 分组留侧写数据;**不冒充自然失效率结论**(见计划 §1)。

### 1.2 排除标准

- 同名/易混物品对(#2:同名须先消歧,本轮直接排除,不把消歧负担混进找回测量);
- 药品仅做**位置**记录与找回,不涉及任何提醒/日期话术(#36 D1 §0 纪律延伸);
- 借用他人(非参与人)保管中的物品;租住/公用空间中不能移动的固定物;
- 纸面线索依赖——物品本身必须有独立找回价值(排除「即使没记录也永远知道在哪」的钉死物,如门钥匙挂钩上的备用钥匙若从不挪动)。

### 1.3 登记表 A(冻结即定稿;试验中真实丢失记 `lost`,不补换)

| --- | --- | --- | --- | --- | --- |
| 1 | S01 | 高频 | 如:串钥匙(共 _ 把) | YYYY-MM-DD HH:MM | |
| … | … | … | … | … | |

## 2. 会话安排

| 项 | 规则 |
| --- | --- |
| Session 数 | 2–4 个,每 session 5–8 件,单 session ≤ 40 分钟(疲劳即停,如实记 `session_aborted`) |
| 顺序 | 每 session 开始前抽签决定本批物品顺序(抵偿学习效应);记录实际顺序 |
| 间隔 | L0 全部录完后**≥24h** 再开始任务(消除刚录完的记忆红利);记录实际间隔 |
| 环境 | 参与人自己家;默认「我的家」个人家庭;网络、手机型号、小程序版本照录(结论页的环境说明) |
| 冲突演练(可选) | ≤1 件:第二台设备在 L5 前抢先改位置制造 `VERSION_CONFLICT`;标 `drill=conflict`,数据单列不入主指标 |

## 3. 任务脚本(每件物品,统一模板 8 步)

> 预计每件 3–6 分钟。研究员只读【】内的话术,其余照录不引导;参与人自己兼任时改为自读+出声思考。

~~~text
【预备(参与人背对/离开房间时)】R1 故意移位
  把物品从记录位置移到别处(别处=参与人事先不知道、研究员抽签或自选的合理位置:
  同房间不同容器 / 不同房间均可;禁止藏到不可能找到的地方,禁止移动第二件物品顶替)。
  记录:移位去向(纸面,参与人不可见)、移位耗时。
─── 参与人回来 ───
R2【"请你找一下 S01,像平时那样用小程序。"】→ 打开首页 → 输入 → 点「找」
  打点:t_search_ms(开始输入→结果出现);match_type;first_hit。
R3【看到详情后先说出:"它说在哪?你觉得它真在那吗?"】(照录第一反应)
  打点:是否把「记录更新于」误读成「位置确认时间」(口径红线,见计划 §2.2-5)。
R4 去 R2 大卡所示位置实地找。
  a. 就在 → 按纸面卡「找到了」→ 打点 t_locate_ms → 跳 R8。
  b. 不在 → 按纸面卡「没在这里」→ 纸面卡翻面:
     【"这条记成'位置待核实'了。上面还留着上次的话:『{location_text 原话}』。
       想想上次用它是什么时候?"】
     打点:t_feedback_ms;clue_helped(参与人原话里是否出现利用旧线索的推理);
     guess_urge(参与人是否直接说"肯定在 X"并想去改,而不是先找)。
R5 人肉找(不限定方式;允许回到 R4 的旧位置再看)。
  打点:t_seek_ms;found_after_feedback;若 5 分钟未找到 → 停止,记 recover_success=false
  + 参与人最终是否靠其他办法找到(照录),物品由研究员放回并如实更新记录(该件
  仍计入分母,纠错结果=false)。
R6 找到后立刻就地改:详情 → 「编辑物品信息」→ 改位置 → 保存。
  打点:t_edit_ms(展开表单→保存成功回执);保存冲突/conflict_hit 及面板处理照录。
R7【"再搜一次,确认现在记得对不对。"】→ 搜索 → 大卡已是新位置 → 实地/目视确认
  → 按纸面卡「找到了」→ 纸面:uncertain→confirmed,confirmed_at←now。
  打点:t_recheck_ms;再搜是否仍 first_hit。
R8 收尾一问(每件,口头,照录):
  【"刚才这一趟,哪一步最烦?哪一步真的帮到你了?"】
~~~

**每件强制时序**:R1 移位必须瞒着参与人完成;研究员(或自兼时的抽签信封)不得在 R5 给任何位置提示。

### 3.1 Session 收尾访谈(每 session 一次)

1. 【"如果小程序以后真有这两个按钮,你每次找到/找不到都会按吗?哪种情况你会懒得按?"】(H3)
2. 【"「位置待核实」这个说法你能看懂吗?你期待它接下来发生什么?"】(H2 文案理解,防「待核实=系统会自己找」的误解)
3. 【"你会担心家人看到'待核实'吗?"】(共享场景侧写,不展开)

## 4. 耗时与纠错记录模板

### 4.1 CSV 字段定义(一行 = 一件物品一次任务)

| 字段 | 类型/枚举 | 说明 |
| --- | --- | --- |
| `item_anon_id` | S01–S20 | 登记表 A 匿名编号 |
| `category` | high_freq / anchor | 高频移动物 / 稳定锚点 |
| `session_id` / `order_in_session` | 字符串 / 整数 | 抽签顺序 |
| `entry_at` / `task_at` | 时间戳 | L0 首确认 / 任务执行(间隔核算,≥24h) |
| `wizard` | self / researcher | 研究员身份(自兼须标) |
| `t_search_ms` / `match_type` / `first_hit` | 数值 / exact·prefix·contains·none / bool | R2 检索 |
| `misread_updated_at` | bool | R3 把「记录更新于」误当位置确认时间 |
| `t_locate_ms` | 数值 | R4a 就在记录位置按下「找到了」的耗时 |
| `found_at_recorded` | bool | R4 走 a 分支(记录仍准) |
| `t_feedback_ms` / `clue_helped` / `guess_urge` | 数值 / bool / 整数 | R4b 待核实反馈与旧线索利用 |
| `t_seek_ms` / `found_after_feedback` | 数值 / bool | R5 人肉找 |
| `recover_success` | bool | R6 保存成功且位置与实况一致 |
| `t_recover_ms` | 数值 | **核心口径:R4b 按下「没在这里」→ R6 保存成功回执** |
| `steps_recover` | 整数 | R4b→R6 的操作步数(每次点击/输入计 1) |
| `t_edit_ms` / `conflict_hit` / `conflict_note` | 数值 / bool / 文本 | R6 编辑保存;冲突面板照录 |
| `t_recheck_ms` / `recheck_first_hit` | 数值 / bool | R7 再搜再确认 |
| `mispress_found` | bool | 没实地见到就按「找到了」(合同越界,目标 0) |
| `silent_overwrite` | bool | 跳过「没在这里」直接改且不留待核实痕(合同越界,目标 0) |
| `session_aborted` / `lost` / `drill` | bool / bool / conflict·none | 中止、真实丢失、演练标记 |
| `protocol_deviation` | 文本 | 任何偏离本脚本的实况 |
| `verbatim_pain` / `verbatim_help` | 文本 | R8 两问原话(去标识) |

### 4.2 纸面速记(现场用,试验后誊 CSV)

```
件号:___ 类别:高频/锚  session:__ 顺序:__
搜:___s(match:___ 首中:是/否) 误读时间:是/否
在记录处找到:是(t:___s)/否 → 没在这里(t:___s)线索帮:是/否 想猜:__次
人肉找:___s 找到:是/否(5 分钟停:是/否)
改位置:___s(冲突:无/有→___) 纠错总:t=___s 步=__
再搜再确认:___s 首中:是/否
越界:没找先按:无/有  静默直改:无/有
最烦:____________  最有用:____________
```

### 4.3 报告口径

- n=20:只报原始数、中位数、逐案例;**不宣称统计显著**,不与任何行业基准比(#2 原则)。
- 核心指标:`recover_success`、`t_recover_ms` 中位数、`clue_helped` 占比、`mispress_found`/`silent_overwrite`(必须为 0 才可谈 GO)。
- 失败逐条归因:检索没命中 / 名字没搜到 / 记录过期 / 人没找到(物品真丢)/ 流程太烦放弃——不得一概归咎于「记错了」(#2 V2 失败分类的 V0 简化版)。
- 所有纸面扫描件与 CSV 本地保存,公开内容须脱敏(位置文本→类别化,如「卧室抽屉→家具内」)。
