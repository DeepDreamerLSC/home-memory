## 2. 「多/少几步」口径(桌面推算,非实测)

- 步数 = 从「产生一个未来事项的念头」到「该事项将来会被可靠触发/找回」所需的关键用户操作数(打开应用、新建、输入名称、输入/确认位置、设定日期、设定重复、确认保存)。
- 本方案基线(切片 A 目标态,见 D1):说一句话(1)→ 核对候选并修正(1-2)→ 确认保存(1)≈ 3-4 步;若候选全对,纠错步为 0。
- 所有数字用于访谈沟通与实验设计,**不得写入对外材料当作实测结论**。实测步数以 E1 记录模板(D1 §7)为准。

## 3. E0 招募筛选问卷(目标 10-15 户)

**单元**:一个家庭(同住视为一户),每户一位主访对象,可另邀一位同住成员旁证。**渠道**:朋友与转介绍(熟人样本,偏差记录在案)。**知情**:录音与匿名记录同意;试验不承诺任何推送能力;可随时退出。

筛选题(电话/微信问卷,约 5 分钟;**所有「是」必须答出具体事例,口头赞同不算**):

| 编号 | 问题 | 记录格式 |
| --- | --- | --- |
| S1 | 过去 3 个月,你是否真的发生过「在家里找不到某样东西」?最近一次是什么、什么时候? | 0 次 / 1-2 次 / 3-5 次 / 6 次以上 + 最近一次事例(物品/时间/找回耗时) |
| S2 | 过去 3 个月,你是否忘记过给家里设备**更换耗材或清洗保养**(滤芯、滤网、油烟机、加湿器等),直到过了时限或出了问题才想起? | 同上 + 事例(设备/超期多久/后果) |
| S3 | 过去 1 年,你是否错过过**保修期、退换窗口、报销/申报截止**这类和物品绑定的日期? | 同上 + 事例(物品/错过什么/损失) |
| S4 | 你是否忘记过**归还**借来的东西(书、器材、充电宝等)? | 同上 + 事例 |
| S5 | 你现在是否已经用系统日历/提醒事项/备忘录/微信收藏管理家务类事项? | 已有固定习惯 / 偶尔用 / 完全不用(记录具体工具名) |
| S6 | 家中是否有需要定期换耗材的设备(净水器/空气净化器/加湿器/饮水机/软水机等)? | 设备清单(名称,不必型号) |
| S7 | 未来 3 个月是否有季节性收纳、搬家或装修整理计划? | 是/否 + 简述 |
| S8 | 排除项:家中主要待管理物品为药品/医疗用品;主访对象未成年;不同意录音或匿名记录 | 命中即婉拒(§6 高风险类别首轮排除) |
| S9 | 匿名画像:年龄段、同住人数、住房形态(自有/租赁) | 编码字段,不收集姓名联系方式之外的身份数据 |

**强弱需求分层**(招募时配额,不向受访者透露分层):

- **强需求层(目标 5-8 户)**:S1 ≥1 次且有具体事例,**且** S2/S3/S4 至少一项有具体事例。
- **弱需求层(目标 4-6 户)**:过去 3 个月无真实事件,但 S6 有耗材设备或 S7 有整理计划。
- **对照必备**:S5「已有固定习惯」至少 4 户——他们是「为什么不用系统提醒」这一关键反证的证人。
- 每户在 E0 结束时自选 **1-3 个真实未来事项**(见 D1 任务卡);周期长达数月的事项只验证「预约提醒的愿望」,不假装已验证半年后的履约价值。

## 4. E0 访谈脚本(30-45 分钟,半结构化)

**前半段盲访**:不展示、不透露本产品;只谈过去与现状。**后半段**才进入 E1 邀约。录音 + 逐字摘关键原话;事件类回答当场填「事件卡」(物品/时间/损失/解决方式)。

### 开场(2 分钟)

> 「今天不推销任何东西,只想聊聊你家东西的日常。整个过程匿名,录音只用于整理笔记,你可以随时叫停。」

### Q1 事件回溯(#36 §4 原问:最近一次错过或想起得太晚的事情是什么?)

- 主问:「最近一次,家里有什么事是你**错过了**、或者**想起来的时候已经晚了**的?随便什么:换滤芯、还东西、保修、找东西都算。」
- 追问:当时怎么发现的?超了多久?造成了什么损失(时间/钱/心情)?谁承担了后果?这种事一年大概几次?
- 记录:事件卡 ×N + 频次估计(仅用户自述,不外推)。

### Q2 现状与替代(#36 §4 原问:目前怎么解决?)

- 主问:「这类事你现在是怎么对付的?」
- 逐行追问(对照 §1 表,只问用户提到的 + 手机上真实装着的):系统日历/提醒事项怎么用的?为什么还在用/放弃了?相册搜过东西吗?微信收藏/置顶放过位置信息吗?买过或考虑过收纳标签/二维码吗?
- 追问(家用库存 App):「有没有装过管库存、记账类的 App?后来呢?」(重点听**放弃原因**)
- 记录:每工具「在用/弃用/从未考虑」+ 弃用原因原话。

### Q3 损失量化(#36 §4 原问:上一次忘找东西损失了多少时间?)

- 主问:「上一次找不到东西,你花了多久找到?最后靠什么找到的?」
- 追问:最久的一次呢?有没有最终放弃没找到、重新买了一份的情况?翻找通常发生在什么时刻(赶时间?)——记录**代价场景**,不只记分钟数。
- 记录:每事件卡补「找回耗时」「结局(找到/放弃重买/至今没找到)」。

### Q4 单选权衡(#36 §4 原问:只能保留一种功能会选谁?)

- 操作:出示三张卡——「位置记忆(说一次,以后查得到在哪)」「提醒(到点被告知该做什么)」「组合(到点被告知 + 顺带告诉你上次确认放在哪)」。先让用户**盲选排序**,再问:「如果选了提醒,到点之后你怎么知道东西在哪?」「如果选了位置,谁来提醒你到点了?」——让用户自己发现组合假设,不引导。
- 追问:「反过来问:什么情况下你会觉得这三个都多余?」
- 记录:排序 + 理由原话 + 用户自己补出的组合场景(如有)。

### 收尾与 E1 邀约(5 分钟)

- 确认 1-3 个真实未来事项(尽可能是 7-14 天内会真实发生的;数月周期的只记愿望)。
- 说明 E1 形态:同屏试用 + 若同意,研究员在既有沟通渠道按约定时间**人工**提醒(明确声明:这不是小程序已支持的功能,是实验模拟)。
- 每条录入的**来源标注**当场声明口径:真实主动 / 研究员提示 / 研究员代录 / 体验任务强制(见 D1 §7 字段 `entry_source`)。
