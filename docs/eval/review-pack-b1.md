## A 组:「第 N 个」行号类(3 例,同一判据,可一并裁)

**判据原文**:行号不是锁定依据——用户只说「第二个/第3个」时绝不按顺序锁定任何一件(行号会随删行漂移),对象不明必须 needs_pick 交点选,绝不猜。

| 例 | 原话 | 期望(关键字段) |
| --- | --- | --- |
| dev-ed-07 | 「把第二个改名成充电宝」(候选 4 件) | needs_pick=true、target 空、edits 空(交点选) |
| val-ed-05 | 「第3个改成小剪刀」(候选含电池等) | 同上(needs_pick 交点选) |
| val-ed-02 | 「充电线改成两米的那条」(两件充电线,「两米」无处锁定) | needs_pick=true + 全量候选进 picks |

- [ ] 三例期望均对(行号/描述锁不定=必须点选)
- [ ] 部分修订:___(如:你认为「两米」足以从两件中锁定?或行号在某些场景可用?)

## B 组:复合限定语类(2 例,同一判据)

**判据原文**:序数+方位复合限定语(「最里面」「最下层」)进 qualifiers 且**留在位置实体里**——v2 规则是只剥纯方位后缀(的/里/上),不剥复合限定语。

| 例 | 原话 | 期望 |
| --- | --- | --- |
| dev-ex-15 | 「充气简放在阳台储物柜最里面」 | location_text=「阳台储物柜最里面」;名称逐字「充气简」不纠成「充气筒」 |
| val-ex-01 | 「遥控器在电视柜最下层」 | location_text=「电视柜最下层」 |

- [ ] 期望对(复合限定语保留在位置里)
- [ ] 修订:___(如:你认为「最下层」该剥掉、位置只留「电视柜」?)

## C 组:多件共位置(1 例)

| --- | --- | --- |
| dev-ex-08 | 「钥匙和充电宝都在玄关抽屉里」 | 两件草稿,mount_path 均为[玄关,抽屉](句尾「里」剥掉) |

| 例 | 原话 | 期望 |
