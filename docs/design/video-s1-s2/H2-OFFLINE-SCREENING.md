# H2 离线可找性筛查(零模型调用)

**状态**:2026-10-18 · 零模型调用 · 脱敏版(仅 Gold ID/计数/时间/哈希)
**目的**:在组织真人 H2 之前,先用已有 S1/S2 输出和关键帧,判断每个目标是否"看得见、找得到、证据足够"。筛查结果直接决定 H2 目标集是否需要替换。

---

## 1. 方法

- **照片证据**:统计 S1 P3(2 轮)与 S2 P3prod(2 轮)中,目标 Gold ID 在 9 张照片里被识别的次数(按抽屉匹配);这是模型识别计数,不等于人眼可见性;Gold 的 `vis.p3` 是冻结可见性基准。
- **视频证据**:统计 S1 V8 与 S2 V6x2/V3batch 中带 box 的命中次数、不同时间点数、最大 box 面积(0–1 画面占比)。
- **关键帧集合**:按 H2 协议构造每目标 6 帧(0/20/40/60/80/100% 时长;目标帧替换最近基准帧);计算目标帧序号、目标帧清晰度(拉普拉斯方差)与集合中位数之比、dHash 集合多样性。
- **人工目检**:逐目标查看目标帧,确认画面里确实是该 Gold 项,而不是模型误读;这一步只做视觉核对,不调用模型。
- **边界**:模型 box 是近似证据,不是人工 Gold 框;D2-019 没有模型 box,采用人工目检确认目标帧清晰,面积按目检估计。所有数字只用于目标筛选,不作为 H2 结果。

## 3. 被替换/修正的目标(重要)

### 3.1 D1-020:目标时间 43.2s 错误 → 修正为 40.27s

- 43.2s 帧实际显示的是另一款游戏封面,不是 D1-020;40.27s 与 46.1s 帧才清楚显示 D1-020。
- 证据:D1-020 的 box 出现在 40.0/40.3s,最大面积 25.7%;40.27s 目标帧清晰度 187.6,高于集合中位数。
- 处理:目标时间改为 40.27s;目标 ID 不变。

### 3.2 D2-020:照片 p6 的识别是误报,视频证据不足 → 移出 H2

- 模型在 p6 识别出 D2-020,box 面积 9.3%;人工目检该 box 圈的不是目标物,而是相邻的另一件物品;模型把非目标误识别为目标。
- 视频侧没有 D2-020 的 box;14.3s 目标帧看不到目标。Gold `vis.p3=0` 与"照片里没有目标"一致,模型照片命中属于假阳性。
- 处理:从 H2 目标集移除;不作为"照片可见"或"视频可见"证据。

### 3.3 D2-022:仅一条低置信边缘框 → 移出 H2

- 唯一视频 box 在 t=0.07s,面积 3.9%,confidence=low,位于画面顶部边缘;6.8s 目标帧看不到目标。
- 处理:从 H2 目标集移除。

### 3.4 替代目标

- **D2-019**(V3):13.0s 目标帧里目标占画面很大、包装文字清楚;没有模型 box,但人工目检确认为目标。补上 D2 抽屉覆盖。
- **D3-021**(V4):14.1s 目标帧里目标盒清楚;5 次 box、4 个时间点、最大 9.4%、清晰度 2.2× 中位数。

## 4. 语料级证据充分度(零调用)

### 4.1 25 个视频独有 C 项

| 指标 | 数量 |
|---|---|
| 有 ≥1 个模型 box | 14 / 25 |
| 无任何 box | 11 / 25 |
| 仅 1 个 box | 6 / 25 |
| ≥2 个 box | 8 / 25 |
| ≥2 个不同时间点 | 5 / 25 |
| 最大 box 面积 ≥5% | 12 / 25 |

**含义**:视频独有项的"可核对证据"并不均匀——近一半没有任何 box,只有约一半有 ≥5% 的清晰框。H2 目标必须从证据强的子集里选;不能假设"视频里出现过"就等于"有可用证据"。

### 4.2 21 个照片/视频共同 C 项

| 指标 | 数量 |
|---|---|
| 照片侧被识别(至少 1 次) | 15 / 21 |
| 视频侧有 box(至少 1 次) | 19 / 21 |
| 两轮照片都未识别 | 6 项(D1-002、D1-009、D2-001、D2-004、D3-024、D3-015) |
| 视频侧无 box | 2 项(D2-015、D3-024) |

**含义**:即使是"照片可见"的共同项,照片侧也只有 15/21 被识别;视频侧 19/21 有 box。视频证据覆盖更广,但这不是用户"找回价值"的证明。

## 5. 结论与建议

1. **H2 目标集修订为**:D1-019、D1-020(40.27s)、D2-019(13.0s)、D3-021(14.1s)、D3-BAT、D3-001。仍是 **4 个视频独有 + 2 个共同**;6×6 任务矩阵/序列不变,只换目标 ID 与时间。
2. **不要使用** D2-020、D2-022 做 H2 目标:前者照片命中是模型误报、视频无证据;后者只有边缘低置信框。
3. **D3-BAT 的名称要泛化**:使用类别泛称而不是具体型号;Gold 的类别级粒度不适合做精确名称任务。
4. **H2 仍待授权**:本筛查不构成真人执行授权;若搭车 #76,需在知情同意里补"家庭收纳照片/关键帧展示"。
5. **下一步**:用修订后的目标搭车 #76 五人走查(每人 +10 分钟,3 个任务);若信号明显再扩到 6 人 H2。全程零模型调用。
