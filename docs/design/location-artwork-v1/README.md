# 位置插画第一版

独立设计图册，也是小程序24款位置插画的矢量源文件。沿用现有 UI 原型的插画与配色变量。

生产素材由 `scripts/generate-location-artwork.js` 生成至 `miniprogram/assets/location-artwork/`。首页长按位置 → 更换插画，可显式保存或恢复自动匹配；手动选择保存在对应家庭的位置节点上。

- 空间 8 张：客厅、卧室、书房、厨房、卫生间、阳台、玄关、车内。
- 家具 8 张：衣柜、书柜、冰箱、桌子、床头柜、鞋柜、抽屉柜、吊柜。
- 收纳 8 张：抽屉、收纳箱、纸箱、收纳篮、文件盒、行李箱、工具箱、通用位置。

打开 index.html，点击图册更新手机卡片预览；输入名称查看自动匹配，手动选择可覆盖自动结果。“自动匹配”恢复名称规则。支持苔绿、暖杏、深海和深色预览。

前三组名称仅组织插画，不改变位置树，不要求用户分类。位置名称匹配使用较长关键词优先，未知名称回退通用位置。示例中的数量均为虚构数据。四张现有空间插画沿用旧原型以供对照，其余为本次扩充。
