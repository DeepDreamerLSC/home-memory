# 拍照识物 · 交互原型 V0.3(#3)

2026-10 前哨调研驱动的六屏交互原型,供设计方案评审(issue 附后)。

## 怎么看

```bash
cd docs/design/issue3-photo-intake
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/prototype.html(不能直接开 file://)
```

真实抽屉照片**不随库分发**(仓库 public,隐私红线;实验产物留本地)。缺图时自动降级为占位底图,识别框与全部交互不受影响。想看完整效果,把三张抽屉照片命名为 `real-1-1024.jpg`、`real-2-1024.jpg`、`real-3-1024.jpg` 放到本目录(勿提交)。

## 六屏

| 屏 | 名称 | 要点 |
|---|---|---|
| ① | 识别确认 | 位置栏(批次级,填一次全批继承)+ 语音条同款底栏:按住说话胶囊撑满左侧、小号墨底黄字保存;框↔清单互点;数量步进器 |
| ② | 按住说话中 | 不跳页,recsheet 同款浮层:压暗+回弹入场+黄圆麦克风脉冲+墨色波形+上滑取消 |
| ③ | 松手→diff 过目 | 语音解析成结构化改动,旧值红划线/新值黄荧光,过目才应用,应用后可连说 |
| ④ | 手动编辑 | 细分类错修复:AI 候选词一键改类(棉柔巾/卫生棉条真实案例);位置默认继承批次 |
| ⑤ | 圈选补识别 | 漏检兜底:用户在照片上画框,「全图+坐标」提问(调研结论:比裁剪再问稳) |
| ⑥ | 找东西·照片+框回放 | 闭环:录入存的 grounding 框,检索时高亮放给用户;无照片降级文字+去补拍 |

## 设计语言

全部令牌取自现有 `miniprogram/app.wxss` 与 `miniprogram/components/voice-bar/voice-bar.wxss`:奶油白底 `#faf8f2`、白卡细描边 `#e8e3d6`、明黄 `#ffe15a` 唯一强调、墨底黄字 CTA+硬投影、录音浮层/波形/脉冲环 1:1 复刻 recsheet。识别框语义:墨实线=已确认、黄虚线=待确认、红虚线=用户动作、黄环脉冲=搜索高亮。

## 数据来源一句话

原型里的识别框坐标、清单条目、候选词案例,全部来自本机 Qwen3-VL-8B-Instruct-4bit(@1024px)对三张真实抽屉照片的实测输出(grounding 坐标为 0-1000 归一化,解析须按最大值自适应量纲),详见设计方案 issue 的调研数据节。
