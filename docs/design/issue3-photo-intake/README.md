# 拍照识物 · 交互原型 V0.4(#3 / #65)

2026-10 前哨调研驱动的六屏交互原型;**V0.4 依架构师评审收紧**(候选三态、数量冻结、照片证据化、逐项裁决、真实按住手势、历史照片语义),设计合同见 issue #65 的 V0.4 评论。

## V0.4 相对 V0.3 改了什么

| 评审问题 | 本版处理 |
| --- | --- |
| AI 高置信=「已确认」误导 | 三态模型:**候选 → 保留(待存) → 已确认(入库成功)**;勾选行标「保留」而非已确认;计数一处来源动态更新;框标签改「预选·/候选·」 |
| 数量步进器引入库存语义 | 冻结:**一条记录=最小建档单位**,数量仅草稿备注(横幅明示「电池×24 只记一条」) |
| 批次位置成无条件事实 | 位置栏语义=候选默认继承+逐件例外+保存前最终确认;不新建位置模型 |
| 坐标按最大值猜量纲 | 原型层面:容器等比跟随原图、禁 `object-fit` 裁切错位;代码注释写明生产合同(适配层声明量纲→存 0-1 相对原图+原图宽高→前端变换;不可信框不显示) |
| 「第3个」行号漂移 | diff 卡明示**按内容锁定草稿 #d3**,不按行号;歧义不执行 |
| diff 只能整句接受/放弃 | **逐项裁决**:按字段拆行,勾几项应用几项;原话保留可回听 |
| `simHold` 假按住、`fakeCircle` 未确认先入列 | 真实按住/松手/**上滑取消(滑回继续说)**/最短按压 250ms;圈选须点「加进清单」才入列,且为未勾选候选 |
| 触控热区 24px | 步进器 36px、保存 44px、复选 26px(生产按 44px 标准,沿用 voice-bar 透明热区层先例) |
| 找物旧照片冒充现址 | 结果卡标「拍摄于某日·当时记录在此」+「历史照片」徽标;位置已变更案例:旧照片作证据、以文字位置为准 |
| 视觉竞争 | 照片默认折叠为**证据条**,点开或点候选行才展开全幅+高亮框;默认焦点=候选清单+保存数 |

## 六屏

| 屏 | 名称 | 要点 |
|---|---|---|
| ① | 识别确认 | 照片=折叠证据条;三态候选清单为主;位置栏(默认继承+例外+最终确认);按住说话胶囊撑满左侧+小号保存 |
| ② | 按住说话中 | recsheet 同款浮层;真实松手/上滑取消(屏①可操作) |
| ③ | 松手→逐项裁决 | 按内容锁定 #d3;字段级勾选应用;原话保留 |
| ④ | 手动编辑 | AI 候选一键改类(棉柔巾真实案例);数量=备注;位置例外 |
| ⑤ | 圈选补识别 | 全图+坐标提问;确认才入列(未勾选候选) |
| ⑥ | 找东西·历史证据 | 照片+框回放但标拍摄时间;位置变更以文字为准,旧照片作证据 |

## 设计语言

全部令牌取自现有 `miniprogram/app.wxss` 与 `miniprogram/components/voice-bar/voice-bar.wxss`:奶油白底 `#faf8f2`、白卡细描边 `#e8e3d6`、明黄 `#ffe15a` 唯一强调、墨底黄字 CTA+硬投影、录音浮层/波形/脉冲环 1:1 复刻 recsheet。框语义:墨实线=AI 预选候选、黄虚线=低可信候选、红虚线=用户动作、黄环脉冲=搜索回放——**全部是候选,不是事实**。

## 数据来源一句话

原型里的识别框坐标、清单条目、候选词案例,全部来自本机 Qwen3-VL-8B-Instruct-4bit(@1024px)对三张真实抽屉照片的实测输出(grounding 坐标 0-1000 归一化;生产坐标合同见上表),详见 #65 调研数据节。
