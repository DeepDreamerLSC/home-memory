## 0. 现状修正(P0-1:语音/照片已有保存后挂树)

#116 原诊断「三入口全不挂树」**不准确**,特此修正。经代码核实的挂载全景:

| 入口 | 挂载机制 | 自动建节点 | 幂等 | 失败语义 |
| --- | --- | --- | --- | --- |
| 语音确认页 | create 后 `locations.ensureAndLink`(行内 mountUpdateId) | **是**(按路径文本补建缺失节点) | mountUpdateId 行内固定 | 不回滚不阻断,轻提示「主界面可补」 |
| 拍照确认页 | 同一 `ensureAndLink`(photo.ts:2276 注释自证) | 是 | 同上 | 同上 |
| D1 位置清点 | 提交时 `node_id` select-existing,服务端校验 | 否 | scene_payload_sig | 失败关闭零写 |
| B 页场景扫描 | **无任何挂载** | — | — | —(← 本波唯一真缺口) |
| 生成向导 | 批量挂载/合并 | 由确认生成 | update_id | 收敛式 |
| 未挂载兜底 | 「尚未归类」根层投影(#36 0.6.0,上限 50 条按 updated_at 倒序) | — | — | — |

家属抱怨的真实成因:视频 B 页零挂载;语音/照片中 **certain=false 或行内无「放进」路径**的物品不挂载落「尚未归类」;以及自动建节点按原话文本产生碎片路径,树越用越乱(「要核对」的体感来源之一)。

## 1. 挂载哲学的统一决定(方案 Z:最小双写风险)

**决定:保留语音/照片的 ensureAndLink 现状不动;B 页新增 D1 式 select-existing;不引入 createItem 节点字段。**

- 语音/照片:既有体验(说一句自动归位)已上线且被真实使用,**零改动、零双写**(P0-1 的"避免重复写入"由此根除:不存在第二条挂树路径)。
- B 页:确认流每行增加可选「归到」行(D1 同款树选择器,只选已有节点,不自动建);**显式携带 node_id 才挂载**,不选照旧纯文本落「尚未归类」。
- 自动建节点的碎片化问题**不在本波解决**(属第二波/向导体验),仅记录为已知债务。

**createItem 幂等(P0-2/决策点 2)**:因不引入 create 节点字段,"创建幂等 vs 位置变更"冲突不存在;挂载信息只在 B 页走 `videoSceneCommit` 既有幂等与签名——**创建时值不可变语义**由"node_id 进 canonical 签名"天然实现(签名冻结即请求冻结,重放换节点=签名失配 OPERATION_CONFLICT)。

**B 页服务端(P0-3/决策点 3)**:B 页无 D1 的位置上下文,独立校验链:`node_id` 存在+本家庭(跨家庭 NOT_FOUND 零写)、**目标是 home 根一律 INVALID**(与 §2 收口同门)、**不施加 D1 子树约束**(B 页可挂全树任意非根节点);`node_id` **仅显式携带时进 `scene_payload_sig`**(旧载荷/不携带的签名逐字节不变,兼容决策点 3)。

## 3. 删除第三去向 unmount(P0-4:并发/部分完成/补偿/重试)

**命名与语义(决策点 1 采纳)**:`deleteLocation` 新增 `mode:"unmount"`;scan 行沿 `location_deleted` 语义;**不删物品、证据、提醒**。

**执行序列(收敛式,参照 migrate)**:删除预览(新增"将转未归类 N 件"计数)→ 逐物品 CAS 解挂载(`update_id="lunmount:"+sha256(node_id+":"+item_id)`,patch=`{location_node_id:""}`,version+1;0 命中三态:重放识别 replayed / 已解挂 already / 版本冲突 VERSION_CONFLICT 附 current,**绝不自动重试冲突件**)→ 全部物品处理后硬删子树节点(与 migrate 同款:子树节点硬删+悬挂挂载补偿扫描)。

**中断与重试**:任意步幂等,中断留"部分解挂+节点仍在"状态,重试从预览重新收敛;物品挂载被并发他改(CAS 失败)→ 整体不阻断,失败件随响应返回,用户核对后重试(与 D1 move 的三态同哲学)。

**「尚未归类」50 条投影上限(架构指出的截断问题)**:unmount 完成提示如实展示总数(N 件已转未归类);投影维持上限 50 + 顶部固定标注「仅显示最近 50 件,共 M 件」(计数来自既有 unmounted_count,**本波不实现分页**,债务记录)。

**客户端弹层(采纳架构建议)**:四选=取消 / 迁移到上一级 / **转为未归类** / 全部删除(全部删除保留独立二次确认不变)。

## 4. 反例矩阵(冻结,实现 PR 测试先行)

**B 页挂载**:选已有非根节点→挂载成功且 location_text=节点路径(服务端权威);不选→纯文本+未归类,行为与现状逐字节一致;跨家庭/不存在→NOT_FOUND 零写;选根→INVALID;同票据重放换 node_id→签名失配 OPERATION_CONFLICT;旧载荷(无 node_id)签名逐字节不变;保存瞬间节点被删→失败关闭零写。

**根禁挂审计**:W1-W6 每条路径"物品挂根→拒绝"反例各一;ensureAndLink 空路径/纯空白→拒绝。

**unmount**:物品全部落未归类投影、location_text 原样保留、节点硬删、scan 转 location_deleted;中断重试收敛;并发他改件 VERSION_CONFLICT 带 current 不自动重试;幂等重放 replayed;预览计数准确;与 migrate/purge 的既有反例零回归。

**全局**:语音/照片挂载链路(ensureAndLink)**零改动**——既有测试全绿是硬门。
