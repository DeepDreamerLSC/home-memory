# 个性化设置实现

已按确认原型实现，2026-10-23。代码保持原生WXML/WXSS/TypeScript，无新增客户端依赖。

## 完成范围

- 首页标题右侧新增固定头像入口，首用态也可进入；家庭切换保留在数量同行。
- 新增 `pages/me`、`pages/profile`、`pages/appearance`、`pages/home-display` 四页。
- 独立 `userProfile` 云函数与 `user_profiles` 集合，资料不依赖当前家庭。昵称头像由用户主动填写，默认人像可进入设置。
- 头像先压缩，再申请10分钟有效的自身上传路径与nonce；保存时校验当前环境、完整路径、nonce、图片头/大小，再用资料version及nonce条件更新。身份始终由服务端OPENID派生，不接受客户端身份。
- 昵称按1–20码点校验。版本冲突明确报错；旧资料与头像不删除。隐藏页保存成功/失败均复位，不产生永久保存中状态；晚到旧回包不回退资料缓存。
- 家庭成员列表优先显示全局资料，旧会员资料保留作兼容回退，不批量改写，也不改变成员权限和家庭作用域。
- 八套配色×深浅模式、系统跟随/手动覆盖；全局页面、原生导航背景和共享录入组件同步。预览草稿不覆盖已应用设置，应用才保存。
- 首页最近记录、到期提示独立开关；只控制展示，不改提醒计划、订阅状态或记录。
- 外观偏好保存本机独立键 `home-memory:appearance:v1`，切换家庭不清空，未实现跨设备同步。
- 144张主题房间/物品PNG，563317字节；生成脚本 `scripts/generate-personalization-assets.js`。原图和普通图标继续共用，不复制16份图标。

## 云端部署步骤（2026-10-23已完成）

1. 创建数据库集合 `user_profiles`，权限设置为所有客户端不可读不可写。`_id` 是服务端派生用户摘要，天然唯一，不需要额外唯一索引。
2. 部署新云函数 `userProfile`（云端安装与仓库其他云函数相同版本的 `wx-server-sdk`）。身份与数据库读写仅经该云函数进行，不开放客户端数据库权限。
3. 部署更新的 `households`，启用成员列表全局资料优先显示。新集合不可用时该列表继续使用旧会员资料。
4. 按现有云存储上传流程使用 `avatars/` 独立路径；不更改现有照片/视频目录规则。不要对正在使用的头像配置自动生命周期删除；本版保留旧文件，不做无引用头像自动清理。
5. 上传小程序开发版，真机验证选择微信头像、昵称快速填写、个人/共享家庭切换、离线及版本冲突。主题与首页开关无需云端写入。
