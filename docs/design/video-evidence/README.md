# 单件视频留证 · 合同与验收清单

**状态**:受控试验 · 未完成微信真机验收前不合并/不部署
**范围**:用户在某件物品详情页明确发起,拍/选一段视频,绑定为该物品的历史视觉证据;查找后主动点击回放。

## 1. 明确不做

- 不做整抽屉批量识物;
- 不按同名跨帧自动合并物理身份;
- 不自动生成高亮框;
- 不默认自动播放;
- 不把视频当当前位置事实,只作为历史证据。

## 2. 上传与归属

1. 客户端先调 `itemsApi.videoUploadBegin({item_id})`,服务端确认物品属当前家庭后签发随机上传票据,并返回固定路径 `video-evidence/<household_id>/<ticket>.<ext>`。
2. 客户端把视频上传到该路径,再调 `videoEvidenceAttach`,携带票据、fileID、时长和尺寸。
3. 服务端校验:票据属当前家庭、未过期、物品仍存活、fileID 实际路径与票据路径逐字一致、文件可通过 `getTempFileURL` 取得临时链接。
4. 校验全过后才落证据行并把票据置 bound;同票据同 fileID 重放幂等。

> 路径前缀本身不是所有权证明。本版通过「服务端签发票据 + 路径完全匹配 + 文件可用性校验」建立可归属的上传凭据;仍不声称验证了云存储对象创建者元数据。

## 3. 保留、撤回与删除

- 证据行保存 `consent_version:"v1"`,客户端只展示该版本。
- 客户端只通过 `videoEvidenceGet` 获得云函数换取的临时链接;集合权限对所有用户不可读不可写。
- 删除单条视频:`videoEvidenceDelete` 先调 `cloud.deleteFile` 删除原视频,成功后才删证据行;云删除失败返回 `VIDEO_DELETE_FAILED`,证据保留可重试。
- 删除物品:服务端在软删前走同一视频清理;云删除失败则物品不删、返回可重试错误。避免「物品已隐藏、私密视频仍留存」。
- 上传成功但绑定失败:客户端在本地按家庭作用域保存 pending 记录,详情页展示「视频待关联」,可重试关联或删除待关联视频。
- 待关联视频未处理时,详情页阻止删除物品。

## 4. 仍存在的残余风险

- 上传成功与客户端写入 pending 之间存在极小的进程被杀窗口;服务端此时尚未收到 fileID,无法主动删除该对象。
- 需要运维配置云存储生命周期兜底:对 `video-evidence/` 下超过 24h 且未被 `video_evidence` 引用的对象进行定期清理。目前仓库不自动执行该策略,体验版开启前必须在云控制台确认。
- 跨家庭成员退出后,原有订阅式临时链接可能在有效期内继续可播;本版依赖临时链接短时有效,不在客户端缓存永久链接。

## 5. 微信真机验收清单(合并前必须完成)

- [ ] 目标机型:至少 iOS + Android 各一台;
- [ ] 横屏/竖屏视频各一段,拍摄与相册选择各一次;
- [ ] 确认上传大小/耗时、弱网中断与重试;
- [ ] 上传成功但 attach 失败时,pending 重试与删除路径;
- [ ] 返回/杀进程重进后 pending 恢复;
- [ ] 播放器默认折叠,用户点击后才播放;旋转/比例/黑边正常;
- [ ] 删除视频后云文件确实删除且回放入口消失;
- [ ] 删除物品后视频清理;云删除失败时物品保留并提示可重试;
- [ ] 跨家庭成员看不到/无法读取视频证据;
- [ ] 退出家庭后临时链接在合理时间内失效。
