## 2. 关键结论
- **推理链复用度高**:本地 VL server 原生多图;逐帧调用形态(每帧一次 vlRecognize)今天就能跑通,**零生产代码改动**;真正缺的是合同层(多图坐标锚定、跨帧合并、帧级证据)——全部属于「先验证价值再决定要不要建」的范畴(#85 宗旨)。
- **离线管线已验证**(见 S0-PROBE-RESULTS):ffmpeg 8.1.1 抽帧+时间戳+清晰度+近重复过滤全链自检通过。
