## 2. 素材 Manifest(状态:BLOCKED_BY_INPUT)
> **范围声明(评审 2026-10-18)**:三个区域×3 媒材**只用于探索性对照**,样本量不支持统计显著性结论,也**不构成独立验证集**(验证集须按 #83 纪律另行扩大规模并封存);本协议产出的 GO/NO-GO 是方向性判断。
- 3 个收纳区域×3 复杂度:简单浅层/密集多物品/遮挡深层;
- 每区域 3 媒介(P1/P3/V 同区域同光线同一次整理后拍摄);**全部需用户拍摄并书面(聊天记录即可)许可;不上传云端,只留本地与评测工作区**;
- 人工 Gold:逐媒介标注「可见/不可见/无法判断」三值——**Gold 按「现实中该区域实际物品清单」建立,再标注各媒介可见性**,杜绝按模型输出倒推;
- Gold 建立人:用户本人(或用户在场时由助手记录),标注表放评测工作区不入库。

## 3. 指标(判定脚本可机器判+人工判两层)
识别:H1——可见召回(仅对 Gold=可见 的物品)、候选精确率、漏检、幻觉(无 Gold 对应)、**同物重复(多候选指向同一实物——**身份参照=人工 Gold ID 对位(评审 B2)**:跨帧/跨图一律以 Gold 对位判身份,相机移动使同一物品在两帧中的框位置不同,**框 IoU 仅在单一帧/单一照片内部可作辅助信号,禁止跨帧用 IoU 判同物**)**、**同名异物误合并(合并后 Gold 对位两实物——重点看 V 组;Gold ID 是唯一身份仲裁,模型侧跨帧合并规则属 S1 设计物,本阶段不评)**;
证据:H2——最佳帧可用性(证据帧清晰度分)、**时间戳可追溯(帧→pts_time 映射保持)**、参照物增益(V 独有:候选框周边环境线索);
基线对照:P1 与 P3 本身互为对照(P3>P1 的增益=多角度价值,V 需**显著超过 P3**才算视频增量,见 RUN-APPROVAL 阈值)。
