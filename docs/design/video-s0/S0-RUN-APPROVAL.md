# S0 Run Approval:真实模型实验点火申请(#85)

## 申请项
1. **素材**:用户按 S0-PROTOCOL §2 拍摄 3 区域×3 媒材(10–15s 视频+三角度照片+单照)并许可;建立人工 Gold;
2. **模型**:本地 Qwen3-VL-8B(8307,已在线)逐帧调用;可选多图单调用冒烟(≤2 次,验合同形状,不记效果);
3. **调用上限**:每媒介≤8 帧×3 区域×2 轮(重跑波动)≤144 次 VL 调用;全本地,**零外部 API、零上传**;
4. **成本**:电费级;预计 30–60 分钟;
5. **隐私边界**:素材与 Gold 留本地评测工作区(/tmp 或用户指定),不入仓库(仓库 public)、不进云存储;
6. **执行**:开发代理跑批+出报告,用户审。

## 建议验收阈值(点火前请确认)
- **GO 条件**:V 的可见召回比 P3 高 ≥10 个百分点(3 区域合计),且候选精确率不低于 P3−3pp,且同物重复率≤P3+5pp;
- H2(证据价值)单独报告不设门:最佳帧清晰度+时间戳可追溯率(应为 100%)+参照物定性观察;
- 满足→进 S1(合同设计:多图坐标锚定/跨帧合并/帧级证据 schema);不满足→HOLD 并出 STOP 分析。
