### 2.5 十七轮口径:「放进」自动挂靠(#18 红线)与家庭切换(#34 合同不弱化)

不新增屏,全部改在既有屏内;原型已实现,以下为落地口径:

- **C1「放进」行**:#18 红线语义从「AI 不确定必须确认,不自动建错误节点」升级为「**确认卡明示将放入的路径,用户确认记住才建路径并放上去**」。certain 时显示将放入的路径(任务示例「主卧 / 柜子上」,原型用自有示意数据「书房 / 书桌 / 右侧第二个抽屉」以与家庭地图自洽),右侧「换」= 进「放进哪儿」选位置弹层——**只从家里已有的位置里逐层选**(原型直接列出示意);certain=false 一律不显示该行 = 照旧先进「尚未归类」,绝不静默建路径。屏底句同步:「点「确认记住」之前,什么都不会保存;「放进」的位置也还没放。」
- **C2 副文「将放入:X」**:certain 行明示挂靠预览;模糊行无副文(=未归类),手补后副文「已补充:X(确认后先放「尚未归类」)」——手动补的自由文本同样不自动上地图。C1b 提示语同口径:「补上位置才能确认;确认后先放「尚未归类」,再到详情里放进具体位置。」
- **D1/首页未归类文案核对**:首页通栏格「N 件待核实」、明细行灰标「位置待核实」不变;V1 背景复刻的「2 件位置待核实」十三轮漏改,本轮修为「2 件待核实」。D1 对未归类物品(原型「双肩包/装修发票」)切专属态:大卡标签「还没放进具体位置」+ 原话 + 「放进具体位置」入口(选位置弹层,与 C1「换」同款,选中后大卡变回「上次记录的位置」);「找到了/没在这里」在该态隐藏——没有位置可核对。
- **首页 fam-chip 三选弹层**(H0/H1 同款):我的家(只有你一人 · 记录不共享)/ 我们家 · 家庭名(✓ 当前,共享中 · N 位家人)/ 家庭管理页(→ F1)。**切换流程**:弹层关 → 骨架屏过渡(#34:不拿上一个家的数据冒充)→ 地图与快到期按新家庭整页刷新(原型「我的家」示意:书房 2 件、无快到期横幅;「我们家」:四房间 + 1 过期 2 临期横幅)→ toast 明示;加载态(X1)不可切换;在 F1/H0 发起切换则落回 H1 地图。
