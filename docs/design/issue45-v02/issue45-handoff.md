| 加载 | X1:骨架屏 + 「正在找…」;家庭头禁点 | 弱网/切家庭时不显示上个家庭旧列表;加载失败不能拿旧数据冒充最新(#34 缓存撤权硬约束) |
| 网络失败 | X2:⚠ + 「网络好像断了」+ 再试一次 | 失败的是本次加载而非记录丢失;不诱导重复录入;重试可恢复 |
| 录音中/取消 | V1:波形 + 上滑取消 + 松开去核对 | 沿用现有录音权限/取消/识别超时/手动回退机制,UI 缩小不牺牲热区 |
| AI 返回空/失败/不完整 | C1b 同构(保留原句 + 手动补) | 原句保留可手动;不静默丢弃也不静默误记 |
| 部分保存失败 | C2 交互延伸 | 三态明确区分:已记住 N 件 / X 件需继续处理 / 部分失败;禁止整体 toast 掩盖(沿用现有逐行幂等合同,已保存行锁定) |
| 键盘/小屏/大字 | H1 键盘避让示意 + 深色切换 | 真机验收项:底栏遮挡、焦点、长名字换行、44px 热区 |
