## 5. 两个待拍板候选的原型呈现

1. **底部语音常驻(候选 1)**:H1/H1b 底部黄条常驻(`voicebar`),H0 用页内大 CTA 过渡。原型内置**键盘态避让示意**——点 H1 搜索框弹出模拟键盘,语音条隐藏并提示「自动避让,不遮挡输入」,「收起键盘」后恢复。T1/T7 真机失败即按 Issue §7 ADJUST(改非固定入口或自适应)。热区:按住区整条 ≥44px,「文字」38px 高、宽 60px(真机实现需 ≥44px,落地时按微信安全区校准)。
2. **物品详情只读结果卡(候选 2,建议 YES)**:D1 常态只读大卡 + 双钮;「找到了/没在这里」按 #2 标注「观察原型,依 #2 另审,不写库」,交互仅 toast 模拟;编辑全部折叠。若 #2 结论为不写 `location_confirmed_at`,双钮退化为「建议」型入口,不影响只读卡结构。
