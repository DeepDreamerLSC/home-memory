## 查看

以 `docs/design` 为根启动静态服务后访问 `/detail-simplification-v1/`。页面外的五个入口用于快速查看各操作；状态下拉框切换未知数量、归零、未归类、待关联视频、位置冲突及无影像样例。深色按钮只改变原型。

原型不联网、不写本机存储，刷新或重置恢复示例。影像为代码绘制的SVG示意，不是真实照片或录像；拍摄、视频播放、微信授权仅展示意图，不能当成原生能力已实现。

## 设计决定

- 首屏：小插画与名称、位置主卡、数量/提醒/影像三行。去掉大幅无照片插画和重复“原话”；名称与原备注在更多里编辑。
- 更新位置：单任务面板，选择归类位置并编辑具体描述，展示确认结果；取消不落入示例记录。归类可以为空，不能用展示重排掩盖文字位置与树挂载的独立语义。
- 数量：点行核对当前总数；保留上次确认信息，支持0与未知；新单位须显式重新核对，不做换算。旧备注不解析为库存。
- 提醒：独立面板设置日期，微信通知仍是显式用户点击；支持处理和清除，二者含义不同，均不自动扣减数量。原型不伪造微信授权成功。
- 留证：同一查看区切换照片/视频，显示拍摄日期及当时位置；播放需主动点击，历史影像不冒充当前事实。待关联视频在详情首屏和查看区均可见。
- 冲突：先刷新最新位置，保留原草稿，再由用户核对确认。不会因刷新而提交原草稿。
- “找到了”：只返回演示查找结果，不更新位置、数量或提醒。

## 实施边界

本原型只验证信息层级和交互路径。原生实施需继续复用现有版本CAS、家庭作用域、稳定重试标识、提醒轮次与订阅手势要求。位置文字更新和位置树挂载并非原子写；需要分别反馈结果，不能照搬本地示例的一次赋值当作完整云端提交。

媒体面板仅演示两张照片、一段视频和待关联状态，不覆盖全部多视频选择、高亮编辑/AI找物、失败恢复和删除资产合同。上述已有能力需在后续原生方案中保留。详情的视频深链仍需能直接定位到目标片段暂停态，不额外绕路。
