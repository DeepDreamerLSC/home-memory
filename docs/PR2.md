> 按 issue #1 分段计划:按住录音、授权/隐私指引、取消重试、文字回退;实测耗时分解。
> 架构不变:语音转文字后**完全复用 PR1 的 extractDraft → confirm → itemsApi 链路**,云函数零改动。

## 一、实现了什么

- **语音识别方案**:微信官方「同声传译」插件(`wx069ba97219f66d99`,免费、实时转写、个人主体可用)。使用前需在小程序后台「设置 → 第三方设置 → 插件管理」添加该插件(README 部署步骤 8)。
- **首页「记一件」双模式**:文字(原有)/ 语音(新增)切换;
  - **按住说话**:按下开始录音,实时显示转写文本;松开完成识别
  - **上滑取消**:录音中向上滑动超过阈值进入"松手取消"状态,松手丢弃本次结果;滑回可恢复
  - **识别完成自动接提取**:转写文本自动填入并触发 extractDraft,进入确认页——录音→转写→AI 提取→确认一条龙
  - **文字回退**:任何失败(权限拒绝、识别失败、插件不可用、AI 不可用)都有明确的中文提示与回退路径
- **授权与隐私**:进入语音模式按住时处理 `scope.record` 授权;拒绝后弹窗引导「去设置」或「用文字」;麦克风用途需在小程序后台「用户隐私保护指引」中声明(提审前必办,见 README)
- **耗时埋点**(issue 要求的耗时分解):每次录音记录 按住时长/转写耗时/字数,本地保留最近 50 条(`voice_timings`);真机开发版中可通过 vConsole 或导出脚本查看 p50 汇总

## 二、代码结构

- `miniprogram/utils/voice.ts`:插件接线与纯逻辑分离——错误码映射、转写清洗、上滑取消判定、耗时聚合均为纯函数(离线可测);控制器回调式封装,manager 注入便于 mock
- `miniprogram/pages/index/`:双模式 UI(模式切换、按住说话按钮、实时转写、取消状态、授权弹窗)
- `app.json`:`plugins.WechatSI` 声明
- 云函数/数据库/其余页面:**零改动**

- E2E:冒烟扩展语音 UI 存在性与模式切换(依赖插件已添加,见 README 步骤 8)

## 五、已知限制

- 同声传译插件为在线识别,无网/弱网时失败并提示(如实回退,不静默)
- 方言与专有名词识别质量受插件能力限制;识别错误的兜底是确认页人工改正(草稿本就是待确认的)
- 模拟器中麦克风依赖宿主机,音质与真机有差异;耗时与体验数据以真机为准
