# 更新日志：0.9.7 → 0.12.0

本日志汇总 0.9.7 之后至 0.12.0 的累计变化。当前 0.12.0 已上传微信开发版，尚未提交审核或发布正式版。

## 拍照记录物品

- 新增拍照识物：从一张照片中识别多件候选物品，核对后批量保存。
- 支持修改物品名称、位置和备注，也可以通过语音提出修改，逐项确认后应用。
- 新增「全保留 / 只留高可信 / 清空」快捷核实，减少逐件勾选。
- 支持批次统一位置及单件位置例外；保存时将物品挂到对应位置层级。
- 优化口语位置拆分，例如「书房桌子的右边抽屉」可拆成多级位置，并支持手动调整。
- 搜索结果和物品详情可查看留存照片及物品标记，帮助回忆当时的摆放情况。
- 优化竖拍照片展示、识别等待提示和保存后自动返回首页；中断后可恢复尚未完成的批次。

## 视频记录与找物

- 支持为单件物品拍摄或选择视频，保存为可回看的历史证据。
- 新增「AI 找这件物品」：分析已有视频，给出候选时间片段及标记，由用户确认后保存。
- 搜索结果新增视频入口，可跳转到已确认的相关片段；视频由用户主动播放。
- 支持扫描一段视频中的多件候选物品，逐件核对后保存，并共用同一段视频证据。
- 修复竖拍视频方向及画面偏移问题；支持点击候选缩略图查看大图。

## 按位置清点与历史管理

- 在位置页新增「拍视频清点这里」，可为房间、柜子或抽屉等位置进行视频清点。
- 核对时可新建物品、关联已有物品，或明确确认后将已有物品移动到当前位置。
- 位置页展示上次清点情况，并支持查看当前位置最近 20 次清点记录及视频。
- 支持删除单次清点记录，已录入的物品及其视频证据保持保留；无其他引用的视频文件会一并删除。
- 未确认任何物品的清点视频，保留满 30 天后按引用情况回收，历史记录显示「视频已过期回收」。
- 完善部分保存失败、重复提交、家庭切换和删除失败后的恢复处理。

## 界面与操作体验

- 重新设计首页、核对页和物品详情，统一配色、插画、卡片、间距与深浅色样式。
- 首页突出搜索、房间地图、近期记录和轻量到期提示，精简重复说明。
- 底部常驻录入栏整合语音与新增入口，可进入文字、拍照及视频记录。
- 核对页支持直接编辑字段和查看归位预览；详情页突出上次记录位置与更新时间。
- 详情页保留「找到了 / 更新位置」操作；点击「找到了」仅返回，不自动修改记录。
- 保留底部按钮高度，将按钮下方留白缩短一半，减少操作区占用。
- 增加按压、弹层、勾选及保存反馈，统一页面交互。

## 个人资料与个性化设置

- 首页右上角新增固定头像入口，进入「我的」设置。
- 支持自行设置头像和昵称；资料独立于家庭，切换家庭后继续使用。
- 家庭成员列表优先展示新设置的资料，并兼容已有成员信息。
- 提供 8 套主题：奶油、苔绿、雾蓝、陶土、墨金、钴蓝、翠绿、莓红，包含 4 套更鲜明的高对比度配色。
- 支持跟随系统、浅色和深色模式，页面、插画及录入组件同步切换。
- 主题可先预览，点击应用后保存；支持恢复默认。
- 新增首页显示设置，可独立开关「近期记录」和「到期提示」。关闭提示仅影响首页展示，不取消提醒。
- 主题和首页显示偏好保存在当前设备，暂不跨设备同步。

## 稳定性与数据保护

- 加强照片、视频及用户资料的归属校验和家庭隔离，防止切换家庭后旧请求误写。
- 完善并发修改冲突提示、上传中断恢复、重复保存及文件删除重试。
- 资料保存失败时保留原资料；头像昵称不会在用户未设置时自动获取。
- AI 识别结果经用户核对后才写入记录；历史照片和视频不代表物品当前实际位置。

## 当前交付状态

- 0.10.0：位置级视频清点已完成部署，并于 2026-10-22 通过用户真机验收。
- 0.11.0：界面改版初版已上传；随后确认的底部留白调整已包含在当前 0.12.0 中。
- 0.12.0：个性化设置已上传开发版，相关资料云函数、家庭成员兼容更新及数据库权限已部署。
- 本地回归测试 1065 项通过，类型检查及原生页面流程验证通过；真实云端资料读取、输入校验和家庭状态接口冒烟验证通过。
- 头像选择、真实资料保存和多设备体验仍需真机验收；0.12.0 尚未提交微信审核或发布正式版。
