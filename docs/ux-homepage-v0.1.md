## 2. 关键状态(全部如实,不混淆)

| 状态 | 呈现 |
| --- | --- |
| 语音 idle | 实心黄底按钮「🎤 按住说话」+ 提示 + 示例句 |
| recording | 按钮加深 + 「录音中 Ns」+ 「松开识别 · 上滑取消」 |
| cancelPending | 按钮变红系 + 「松手取消本次」 |
| transcribing | 「识别中…」(按钮禁用感) |
| extracting | 「AI 整理草稿中…」(识别完成后自动接提取) |
| ASR 失败/没听清 | toast「没听清,请重试或改用文字」(噪音不误报 AI 不可用) |
| 权限拒绝 | 弹窗:去设置 / 用文字 |
| AI 提取失败 | 弹窗「AI 暂时不可用」→ 手动录入(保留已识别文本) |
| 文字模式 | 次级入口「改用文字」,textarea 保留用户输入;回语音随时切 |
| 搜索 未输入 | placeholder「东西名,如:降压药」 |
| 搜索 查询中 | 按钮变「…」 |
| 搜索 命中/多条/同名 | 列表全量展示,同名列出多件,不挑一条 |
| 搜索 空 | 引导去记一件 |
| 搜索 失败 | 红色错误文案 |
| 确认页 | 「AI 草稿,请确认」黄色横幅——草稿与已确认事实视觉分离;未确认绝不提示已记住 |

## 3. 品牌规范(冻结候选)

- 色彩:奶油白 `#FAF8F2`(底)、明黄 `#FFE15A`(唯一强调)、墨黑 `#191919`(文字);一屏仅一个高对比强调面
- 去掉:多层卡片阴影堆叠、虚线框、蓝色系按钮、大段重复留白
- 文案俏皮但事实准确:「东西放哪儿了?我记得。」;位置一律写「上次记录」;查无此物如实说
- 导航栏标题与页内品牌头部统一为「我靠东西呢」;确认/详情页保留任务性标题(确认记录/物品详情)

## 4. 入口映射(保留与挪动)

| 现有入口 | v0.1 位置 |
| --- | --- |
| 找东西输入+查询 | 首卡片,搜索优先 |
| 语音按住说话 | 第二卡片主视觉(默认语音) |
| 文字录入 | 「改用文字」次级链接(保留输入文本) |
| 最近记录 | 第三卡片紧凑列表,点击进详情 |
| 确认/详情/删除 | 不变(全局配色随品牌刷新) |
| 数据 API / 云函数 / 录音会话生命周期 | **零改动** |

## 5. 用户 UI 示意对齐(2026-10-10 第二版)

开发者提供了 UI 示意存档(对话中的首页结构示意),v0.1 第二版按其对齐:

- 搜索紧跟品牌头部(独立区,不占卡片),placeholder「搜钥匙、证件、充电宝…」
- 语音按钮主文案「按住说话,松开记住」,示例「比如说:"充电宝放在书房抽屉里"」
- 品牌语气文案(事实信息仍准确客观):录音中「说吧,我记着呢。」/ 上滑取消「好,当我没听见。」/ 识别中「整理你刚说的话…」/ 提取中「核对物品和位置…」/ 搜索无结果「糟了,这件我还真没记住。」/ 保存成功「记住了,下次问我。」
- 卡片收敛为两张:顺手记一件、最近记住的
