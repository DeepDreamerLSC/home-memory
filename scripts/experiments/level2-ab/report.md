# Level 2 卡通化 A/B 对照评审报告——「卡通化前是否需要 AI 抠图」
日期:2026-10-11

**结论:B-needed(引入抠图),置信度中等。** 在 6 物品同框对照(同裁剪框/同 prompt/同 seed=42/同管线)中,背景污染维度 B 以 6:0 全胜(A 有 4 例背景渗入、其中 3 例明显),三色简笔画风格约束 B 全部达标而 A 违反 2 例;身份保真维度双方互有胜负且**均无「认错成同类」级失败**,不构成 A 的决定性优势;抠图最大风险「误删部件」本轮零实锤(关键疑点经复核排除,见 §3)。按 Generation Runtime Contract「身份保真优先于严格风格」的排序,B 恰好不损失身份、又消除了 A 的背景污染,是帕累托改进方向。

评图方式声明:本报告图片判断由 VLM 辅评(analyze_image,共 9 次调用:6 张五格拼图 + 3 项分歧复核)完成,非人眼直接评审;拼图与复核图为本轮派生产物,在 `/tmp/level2-ab/review/`,可人工复验。确证/推测在下文逐条区分。

## 1. 实验设置回顾(材料:prep.py / run_cartoon.py / gen-log.jsonl)

- 预处理(prep.py):rembg `isnet-general-use` 分割 → 蒙版 alpha>128 的 bbox 每边外扩 10% 作为**两组共用的裁剪框**(crop-boxes.json 记录 6 组坐标)→ A=裁剪 RGB 白底 1024 方图;B=同框裁剪+alpha 抠图白底。两组唯一差异=是否去背景。
- 生成(run_cartoon.py):Qwen-Image-Edit-2511 / bfloat16 / MPS,30 步,true_cfg 4.0,seed 42,1024×1024,统一「身份保真强化」prompt(奶油白 #FAF8F2 底 + 墨黑 #191919 线 + 明黄 #FFE15A 点缀,negative 含「乱码文字」)。
- 物体前景占比(crop-boxes.json `fg_ratio`):麦克风 0.035、美工刀 0.064、猕猴桃 0.17、手机 0.24、鼠标 0.24、手柄 0.31——背景面积普遍很大,模拟用户随手拍。

## 3. 关键分歧点复核(确证 vs 推测的边界)

1. **美工刀 B 产物推钮缺失的归因(已复核)**:对 B 输入图(recheck-Binputs.png)单独询问,VLM 确认刀背滑动推钮**在抠图输入中完整存在**,轮廓无缺口——故产物缺推钮属生成阶段丢失,A 产物同样存在小部件丢失类风险,**不构成抠图误删的证据**。
2. **猕猴桃 A 污染定性(已复核)**:对 A 产物单独盲问(不带对照),VLM 独立指出画面含碗边缘线条、条纹纹理、灰色阴影块且形态与「照片背景实物」一致——污染定性从「对照推测」升级为「独立确证」。
3. **麦克风 B 头部绿残迹(已复核)**:B 输入中头部上缘确有非白残留像素,属 rembg 边缘质量问题,可通过边缘羽化/收缩 1-2px 缓解,量级远小于 A 的背景污染。
4. 推测成分声明:手机样本「三摄为模型幻觉补全」基于源图熄屏不可见背面+产物含三摄的推断,属合理推测;麦克风 B「疑似少部件」VLM 不确定度高,本报告按未定论处理,不计入 B 的扣分。

## 4. 成本账

- 预处理(crop-boxes.json `sec` 字段,准备员记录):6 张合计 **5.1s**(1.5+0.8+0.7×4,含 isnet 推理+裁剪+缩放+白底合成;isnet session 加载未单独计时)。B 相对 A 的边际成本 = 一次 alpha 合成(prep.py:82-86),**计算上≈0**;真正成本是引入 rembg/isnet 依赖(约 176MB onnx 模型 + onnxruntime)。
- 生成(timings.md / gen-log.jsonl):12 张合计 **5032s(约 84 分钟)**,单张 414-422s;A 组 2519s / B 组 2513s——生成耗时与是否抠图无关。模型加载 27s。
- **B 路线增加的复杂度**(架构视角):
  1. 分割模型依赖(rembg isnet;云端部署则多一个推理服务/调用);
  2. 误删风险:本轮 6 样本 0 实锤,但细长/低对比/反光部件类目是已知风险面,建议上线前用此类物品补测;
  3. 边缘残迹(麦克风例)需后续加 alpha 收缩/羽化处理;
  4. 反面论证——A 若要做到「智能裁剪」同样需要分割模型出 bbox,届时 B 的增量仅剩 alpha 合成一步;本轮 A 的紧框本身就借用了分割结果,B 的边际复杂度因此更低。

## 5. 局限与必须明示的事项

1. **本轮「适当裁剪」的框来自分割蒙版 bbox 外扩 10%(受控对照设计)**,即 A 是「理论上最强的裁剪版」;真正的无 AI 智能裁剪/主体检测是**独立未做项**(任务书已划出本轮不做)。若生产采用更松的手动/中心裁剪,A 的背景污染预期只会比本轮更重——这只会加强 B-needed 的方向。
2. 样本仅 6 张物品、单机(M5 Max MPS)、单模型(Qwen-Image-Edit-2511)、单 seed(42),每物品每路线仅 1 次生成,**结论为探索性**,存在采样与随机性噪声;猕猴桃/美工刀的 B 优势幅度大(结论较稳),手机/手柄/鼠标的细节差异幅度小(可能随 seed 摆动)。
3. 图片评审由 VLM 辅评完成,虽经三处二次复核,仍不能替代人眼;盲评集即为此准备。
4. 仓库零写入:全部产物在 /tmp/level2-ab/(out=产物,review=评审拼图,blind=盲评集),未触碰仓库与生产代码。

### 结论修订(按 §6 预登记规则:盲评推翻即回滚)

人工整体偏好 A 4:2,且 VLM 确证的 A 背景污染(猕猴桃/美工刀)并未使用户减分——**在卡通化语境下,轻中度背景渗入的可感伤害低于 VLM 评估权重**。据此**回滚 §「B-needed」建议**,修订为:

> **A 为默认(裁剪后直接卡通化,零分割依赖);B 作为按需分支保留**——本轮 B 的两胜各有实质理由(一胜来自 A 的身份级失败、一胜在细节同损下靠背景干净),「按需」场景真实存在但非默认路径。V1 落地形态建议:用户对生成结果不满意时手动「重试(换抠图版)」,或质检环节判定后二选一,不做自动路由。
